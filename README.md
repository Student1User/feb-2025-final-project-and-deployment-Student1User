# 💻 TechBlog - Modern Technology Blog Website

TechBlog is a fully responsive, multi-page blog website built with HTML5, CSS3, and JavaScript. It focuses on delivering high-quality content related to technology, programming, and digital trends. The site is designed with modern UI/UX principles and optimized for performance, accessibility, and mobile-first experiences.

## 📁 Project Structure

```
BLOG-WEBSITE/
│
├── css/
│   └── styles.css              # Main stylesheet
│
├── js/
│   ├── about.js                # About page logic
│   ├── blog.js                 # Blog listing and filtering
│   ├── contact.js              # Form validation and feedback
│   ├── image-handler.js        # Dynamic image handling
│   ├── main.js                 # Main functionality shared across pages
│   └── particles.js            # Particle animations
│
├── about.html                  # About page
```

## 🌟 Features

- ✅ **Responsive Design**: Works flawlessly across devices and screen sizes
- 🌗 **Dark/Light Mode**: User toggle with saved preference
- 🔄 **Dynamic Blog Content**: JavaScript-powered filtering and pagination
- 🧩 **Interactive UI**: Animated elements and form feedback
- ♿ **Accessibility**: Semantic HTML and ARIA roles for assistive technology
- ⚡ **Performance Optimized**: Fast loading and efficient rendering
- 🌐 **Cross-Browser Support**: Compatible with all modern browsers

## 📄 Pages Overview

- `index.html`: Homepage with featured posts, team section, and newsletter signup
- `blog.html`: Blog listing with category filters and search
- `about.html`: Information about the blog, team, and mission
- `contact.html`: User contact form with client-side validation
- `thank_you.html`: Form submission confirmation
